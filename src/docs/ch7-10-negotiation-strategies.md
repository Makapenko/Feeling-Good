# Глава 7-10: Стратегии переговоров

## Анализ главы

### Ключевая идея
Вместо того чтобы тратить энергию на гнев, лучше сосредоточиться на получении желаемого результата через эффективные переговоры.

Глава предлагает практические техники для ситуаций, когда нужно добиться результата от другого человека, не вступая в конфликт и не разрушая отношения.

### Основные принципы техники:

1. **Комплимент** - начните с похвалы за то, что сделано правильно
2. **Обезоруживание** - согласитесь с аргументами оппонента, лишив его запала
3. **Прояснение цели** - спокойно и твердо изложите свою позицию

### Цикл переговоров
Повторяйте три техники в разных комбинациях до достижения результата:
- Комплимент → Обезоруживание → Прояснение
- Избегайте оскорблений и ярлыков
- Используйте ультиматумы только в крайнем случае
- Выражайте недовольство дипломатично

### Пример из главы
Диалог с плотником о плохо установленных шкафах:
- **Комплимент**: "Мне понравились отдельные элементы вашей работы, особенно облицовка"
- **Обезоруживание**: "Это правда, они не так хорошо сделаны, как более дорогие шкафы"
- **Прояснение**: "Тем не менее оставлять их в таком виде неприемлемо"
- **Результат**: Конструктивное решение проблемы

## Предложение по реализации

### Название компонента
`NegotiationStrategies` - Стратегии переговоров

### Структура интерфейса

#### 1. Заголовок и описание
```
"Стратегии переговоров"
Описание трех техник с примерами использования
```

#### 2. Форма создания сценария переговоров
**Поле 1: Ситуация**
- Тип: `textarea`
- Placeholder: "Опишите ситуацию, где вам нужно добиться результата от другого человека..."
- Подсказка: "Например: плохо выполненная работа, невыполненные обещания, конфликт интересов"

**Поле 2: Желаемый результат**
- Тип: `textarea`
- Placeholder: "Чего именно вы хотите добиться?"
- Подсказка: "Будьте конкретны: что должно быть сделано, к какому сроку, как именно"

**Поле 3: Техники переговоров**
- **Комплимент**: `textarea` - "Что вы можете похвалить в этом человеке или его работе?"
- **Обезоруживание**: `textarea` - "С чем вы можете согласиться в его возражениях?"
- **Прояснение**: `textarea` - "Как вы спокойно и твердо изложите свою позицию?"

#### 3. Дополнительные стратегии
**Поле 4: Альтернативные подходы**
- Тип: список с возможностью добавления
- Placeholder: "Дополнительная стратегия..."
- Примеры: "Предложить компромисс", "Установить дедлайн", "Найти общую выгоду"

**Поле 5: Чего избегать**
- Тип: список с возможностью добавления
- Placeholder: "Что НЕ стоит говорить или делать..."
- Примеры: "Не используйте оскорбления", "Не выдвигайте ультиматумы сразу"

#### 4. Кнопка сохранения
- Текст: "Сохранить план переговоров"
- Активна при заполнении основных полей

#### 5. История планов переговоров
- Аккордеон с сохраненными планами
- Формат заголовка: "Дата + краткое описание ситуации"
- При раскрытии: полный план + статус (планируется/в процессе/завершен)

### Техническая реализация

#### Структура данных
```typescript
interface NegotiationPlan {
  id: string;
  situation: string;
  desiredResult: string;
  compliment: string;
  disarming: string;
  clarification: string;
  additionalStrategies: string[];
  avoidList: string[];
  status: 'planned' | 'in_progress' | 'completed';
  outcome?: string; // результат переговоров
  timestamp: string;
}
```

#### Переиспользуемые компоненты
- `ChapterLinkButton` и `FavoriteButton` - для навигации
- `createBaseExercise` - для создания упражнения
- Паттерн динамических списков из `PleasureSheet`
- Стили форм из других компонентов

#### Уникальные особенности
1. **Структурированный план** - четкая последовательность действий
2. **Три обязательные техники** - комплимент, обезоруживание, прояснение
3. **Статус выполнения** - отслеживание реализации планов
4. **Практическая направленность** - фокус на конкретные действия

### Отличия от существующих компонентов

#### От `ExpectationAdjustment`:
- Фокус на активном воздействии, а не на принятии
- Конкретные техники переговоров вместо изменения ожиданий

#### От `VerbalJudo`:
- Не защита от критики, а активное достижение целей
- Структурированный подход к переговорам

#### От `AngerProsCons`:
- Не анализ гнева, а альтернатива гневу
- Практические навыки вместо рефлексии

#### От `HotCoolThoughts`:
- Не работа с мыслями, а планирование действий
- Внешняя направленность (на других) вместо внутренней работы

### Психологическая ценность

1. **Контроль над ситуацией** - активная позиция вместо пассивного страдания
2. **Развитие навыков** - практические техники для реальных ситуаций
3. **Снижение конфликтности** - конструктивный подход к разногласиям
4. **Повышение эффективности** - достижение результатов без разрушения отношений

### Дополнительные возможности

#### Режим "Репетиция"
- Возможность проигрывать диалог в уме
- Поле для записи предполагаемых возражений
- Подготовка ответов на каждое возражение

#### Оценка результатов
- После переговоров: поле для записи исхода
- Анализ: что сработало, что нет
- Уроки для будущих переговоров
