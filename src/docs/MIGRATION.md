# Миграция с React Context API на Redux

В этом документе описана миграция приложения "Терапия настроения" с использования React Context API на Redux.

## Причины миграции

1. **Улучшение организации кода**: Redux предоставляет более структурированный подход к управлению состоянием.
2. **Упрощение отладки**: Redux DevTools позволяет отслеживать изменения состояния.
3. **Повышение производительности**: Redux позволяет избежать ненужных ререндеров компонентов.
4. **Масштабируемость**: Redux лучше справляется с большими объемами данных и сложными состояниями.
5. **Улучшенный UX**: Централизованное управление уведомлениями.

## Выполненные изменения

### 1. Создание Redux Store

- Создан `store.ts` с конфигурацией Redux-хранилища
- Добавлен middleware для сохранения состояния в localStorage
- Добавлен middleware для автоматического удаления уведомлений
- Создан механизм уведомлений для улучшения пользовательского опыта

### 2. Слайсы Redux

- **progressSlice.ts**: Основной слайс для хранения прогресса пользователя
  - Управление главами
  - Управление активностями
  - Сохранение результатов тестов
  - Отслеживание прогресса
  
- **mobileSlice.ts**: Слайс для мобильного интерфейса
  - Управление активной вкладкой в мобильном представлении
  
- **notificationSlice.ts**: Слайс для уведомлений
  - Добавление и удаление уведомлений
  - Автоматическое удаление уведомлений по таймеру

### 3. Миграция данных

- Создан `migrateLegacyData.ts` для миграции данных из старого формата Context API в новый формат Redux
- Добавлен флаг `reduxMigrationCompleted` в `UserProgress` для отслеживания статуса миграции
- Добавлен вызов функции миграции при запуске приложения

### 4. Обновление компонентов

- **Все компоненты**, использующие Context API, обновлены для работы с Redux:
  - Заменены импорты `useContext` и `useProgress` на `useAppDispatch` и `useAppSelector`
  - Обновлены вызовы dispatch для использования action creators
  - Удалены контекстные провайдеры из компонента App

- **Обновленные компоненты**:
  - Все компоненты активностей
  - Навигационные компоненты
  - Компоненты уведомлений
  - Компоненты мобильного интерфейса

### 5. Удаление устаревших файлов

- Удалены устаревшие файлы контекстов:
  - `ProgressContext.tsx`
  - `MobileContext.tsx`
  - `NotificationContext.tsx`
  - `progressReducer.ts`

## Преимущества после миграции

1. **Упрощение структуры приложения**: Все состояние теперь хранится в одном месте
2. **Улучшение отладки**: Возможность отслеживать все изменения состояния
3. **Модульность**: Улучшение организации кода с использованием слайсов
4. **Прозрачность**: Все изменения состояния происходят через actions, что делает поток данных более прозрачным
5. **Типизация**: Улучшенная типизация с использованием TypeScript
6. **Улучшенный UX**: Автоматические уведомления при ключевых действиях

## Выполненные улучшения

### 1. Внедрение селекторов для оптимизации

В рамках оптимизации кода были внедрены селекторы с использованием `createSelector` из Redux Toolkit, что позволило:

- **Мемоизировать данные**: Избегать ненужных перевычислений при отсутствии изменений в state
- **Создать композитные селекторы**: Комбинировать базовые селекторы для получения сложных данных
- **Упростить доступ к данным**: Создать удобные хуки для работы с селекторами

Были добавлены следующие файлы и компоненты:

- `src/redux/selectors.ts` - центральный файл со всеми селекторами
- Обновлен `src/redux/hooks.ts` с добавлением удобных хуков для селекторов

### 2. Разделение логики actions для большей модульности

Для улучшения организации кода и создания возможностей для переиспользования логики, были разделены actions по функциональным группам:

- `src/redux/actions/chapterActions.ts` - actions для работы с главами
  - `loadChapter` - загрузка контента главы
  - `updateChapterTime` - обновление времени чтения главы

- `src/redux/actions/activityActions.ts` - actions для работы с активностями
  - `toggleFavoriteActivity` - добавление/удаление из избранного с уведомлением
  - `setSpecialContent` - установка специального контента с уведомлением
  - `addExercise` - добавление упражнения с уведомлением
  - `saveTestResultWithNotification` - сохранение результатов теста с уведомлением

- `src/redux/actions/unlockActions.ts` - actions для разблокировки контента с уведомлениями

- `src/redux/actions/index.ts` - индексный файл для экспорта всех actions

### 3. Преимущества от этих улучшений

- **Улучшенная производительность**: Мемоизированные селекторы кэшируют результаты
- **Чистые компоненты**: Компоненты используют специализированные хуки вместо прямого доступа к state
- **Переиспользуемость логики**: Вынесенные actions легко использовать из разных компонентов
- **Уменьшение дублирования кода**: Логика уведомлений включена в actions
- **Изоляция побочных эффектов**: Асинхронная логика изолирована в thunks
