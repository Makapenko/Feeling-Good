# Глава 7-12: Мысленная репетиция

> **Обновлено:** Упрощен подход к реализации, сделан акцент на практичности и регулярности, убраны избыточные функции. Фокус на ежедневной практике согласно комментарию разработчика.

## Анализ главы

### Ключевая идея
Гнев имеет взрывной характер - к тому времени, как вы осознаете, что расстроены, вы уже потеряли контроль. Мысленная репетиция помогает нейтрализовать гнев заранее, подготавливая вас к реальным ситуациям.

Это обобщающий метод, который объединяет и позволяет использовать все изученные ранее техники управления гневом.

### Основные принципы техники:

1. **Создание иерархии гнева** - ранжирование ситуаций от +1 (наименее расстраивающие) до +10 (максимальная ярость)
2. **Пошаговая репетиция** - детальное мысленное проигрывание сценариев
3. **Замена мыслей** - от "горячих" к "прохладным"
4. **Представление успешного исхода** - визуализация позитивного разрешения
5. **Регулярная практика** - повторение каждую ночь до автоматизма

### Процесс мысленной репетиции:

#### Шаг 1: Негативный сценарий
- Ярко представить провокационную ситуацию
- Записать "горячие" мысли
- Вообразить потерю контроля
- Оценить уровень расстройства (0-100%)

#### Шаг 2: Позитивный сценарий
- Заменить мысли на "прохладные"
- Представить расслабленное состояние
- Визуализировать тактичное решение проблемы
- Вообразить успешный исход

#### Шаг 3: Практика
- Повторять позитивный сценарий каждую ночь
- Довести до автоматизма
- Подготовиться к реальной ситуации

### Пример из главы
Ситуация в ресторане - медленное обслуживание:
- **Горячие мысли**: "Чертовы официанты ни хрена не умеют! Ленивые ублюдки!"
- **Прохладные мысли**: "Официанты заняты и не заметили меня. Нет смысла кипятиться"
- **Действия**: Тактично объяснить ситуацию, сделать комплимент, повторить просьбу
- **Результат**: Получить отличное обслуживание и насладиться едой

## Предложение по реализации

### Название компонента
`MentalRehearsal` - Мысленная репетиция

### Простая и практичная структура

#### 1. Заголовок и описание
```
"Мысленная репетиция - ежедневная практика управления гневом"
Краткое объяснение: создайте список ситуаций, практикуйте каждый вечер
```

#### 2. Создание списка ситуаций (Иерархия гнева)
**Форма добавления:**
- `textarea`: "Опишите ситуацию, которая вас расстраивает..."
- `slider`: "Уровень гнева от 1 до 10"
- Кнопка "Добавить в список"

**Список ситуаций:**
- Автоматическая сортировка по уровню гнева (от 1 до 10)
- Возможность редактировать и удалять
- Кликабельные карточки для выбора ситуации на вечер

#### 3. Ежедневная практика (выбранная ситуация)
**Основная форма для вечерней практики:**

**Поле 1: Горячие мысли**
- `textarea`: "Какие 'горячие' мысли у вас возникают в этой ситуации?"
- Placeholder: "Например: 'Этот человек специально меня игнорирует!'"

**Поле 2: Прохладные мысли**
- `textarea`: "Замените на 'прохладные' мысли"
- Placeholder: "Например: 'Возможно, он просто занят и не заметил меня'"

**Поле 3: Позитивный сценарий**
- `textarea`: "Представьте, как вы успешно выбираетесь из ситуации"
- Placeholder: "Опишите детально позитивный исход..."

**Поле 4: Результат**
- `slider`: "Сколько гнева вы испытываете после визуализации? (0-100%)"
- `textarea`: "Заметки о практике (необязательно)"

**Кнопка:** "Сохранить практику за сегодня"

#### 4. Календарь практики
**Простое отслеживание:**
- Календарь с отметками дней практики
- Streak счетчик (дни подряд)
- Быстрый доступ к практике за любой день

#### 5. Прогресс по ситуациям
**Для каждой ситуации:**
- График изменения уровня гнева по дням
- Среднее значение за последние 7 дней
- Статус: "в работе" / "освоена" (когда гнев стабильно ниже 30%)

#### 6. История практик
**Простой список:**
- Дата + ситуация + результат (уровень гнева)
- Возможность просмотреть детали любой практики
- Фильтр по ситуациям

### Техническая реализация

#### Структура данных
```typescript
interface AngerSituation {
  id: string;
  description: string;
  angerLevel: number; // 1-10 изначальный уровень гнева
  createdAt: string;
}

interface DailyPractice {
  id: string;
  situationId: string;
  date: string;
  hotThoughts: string;
  coolThoughts: string;
  positiveScenario: string;
  angerAfter: number; // 0-100 уровень гнева после практики
  notes?: string;
  timestamp: string;
}

interface MentalRehearsalExercise {
  id: string;
  type: 'mental_rehearsal';
  situations: AngerSituation[];
  practices: DailyPractice[];
  completedAt: string;
}
```

#### Переиспользуемые компоненты
- `ChapterLinkButton` и `FavoriteButton` - для навигации
- `createBaseExercise` - для создания упражнения
- Слайдеры из других компонентов (PleasureSheet, AngerProsCons)
- Календарь как в `ProgressCalendar` для отслеживания дней практики

#### Уникальные особенности
1. **Простая иерархия** - список ситуаций с рейтингом 1-10
2. **Ежедневная практика** - фокус на регулярности, а не сложности
3. **Отслеживание прогресса** - динамика снижения гнева по каждой ситуации
4. **Практичность** - минимум полей, максимум пользы

### Отличия от существующих компонентов

#### От `HotCoolThoughts`:
- Не просто замена мыслей, а полная репетиция ситуации
- Включает планирование действий и визуализацию исходов

#### От `ExpectationAdjustment`:
- Активная подготовка к ситуациям, а не принятие поведения
- Фокус на собственных реакциях и стратегиях

#### От `PreciseEmpathy`:
- Не понимание других, а подготовка собственных реакций
- Практическая отработка навыков

#### От `NegotiationStrategies`:
- Не планирование переговоров, а общая подготовка к провокациям
- Включает эмоциональную подготовку

### Психологическая ценность

1. **Предотвращение импульсивных реакций** - готовность к ситуациям
2. **Автоматизация навыков** - превращение техник в привычки
3. **Повышение уверенности** - знание, что у вас есть план
4. **Снижение тревоги** - предсказуемость и контроль
