# Глава 7-7: Научитесь ожидать неадекватного поведения

## Анализ главы

### Ключевая идея
Фрустрация = Отвратительное поведение + Неправильные ожидания

Когда мы не можем изменить поведение других людей, единственный выход - изменить свои ожидания. Глава учит принципу: если человек ведет себя определенным образом, то он **должен** вести себя именно так (с его точки зрения).

### Основные принципы техники:

1. **Понимание логики поведения** - разобраться, почему человек ведет себя именно так
2. **Принятие неизбежности** - принять, что такое поведение нормально для этого человека
3. **Изменение ожиданий** - перестать ждать от человека того, что он не может дать
4. **Разработка стратегий** - создать план, как реагировать на такое поведение
5. **Сохранение контроля** - не давать другим людям контролировать ваши эмоции

### Пример из главы
Сью и проблемы с дочерью партнера Сэнди:
- **Проблема**: Сэнди лжет, крадет, устраивает беспорядок
- **Старая реакция**: "Она не должна так поступать! Это нечестно!"
- **Новое понимание**: Сэнди - манипулятор по природе, она считает, что внимание - вопрос выживания
- **Результат**: Сью перестала расстраиваться, изменив ожидания

## Предложение по реализации

### Название компонента
`ExpectationAdjustment` - Корректировка ожиданий

### Структура интерфейса

#### 1. Заголовок и описание
```
"Научитесь ожидать неадекватного поведения"
Описание техники с примером из главы
```

#### 2. Форма создания записки
**Поле 1: Ситуация и человек**
- Тип: `textarea`
- Placeholder: "Опишите ситуацию и человека, чьё поведение вас расстраивает..."
- Валидация: обязательное поле

**Поле 2: Записка-объяснение**
- Тип: `textarea` (большой)
- Placeholder: "Напишите записку-объяснение, почему этот человек ДОЛЖЕН вести себя именно так..."
- Подсказка: "Используйте формат: 'Почему [имя] должен вести себя [описание поведения]'"
- Валидация: обязательное поле

**Поле 3: Стратегии реагирования**
- Тип: `input` + кнопка "Добавить"
- Placeholder: "Новая стратегия реагирования..."
- Отображение списка добавленных стратегий с возможностью удаления
- Валидация: минимум 1 стратегия

#### 3. Кнопка сохранения
- Текст: "Сохранить записку"
- Активна только при заполнении всех полей

#### 4. История записок
- Аккордеон с записками
- Формат заголовка: "Дата + краткое описание ситуации"
- При раскрытии: полное содержание + кнопка удаления

### Техническая реализация

#### Структура данных
```typescript
interface ExpectationAdjustmentRecord {
  id: string;
  situation: string;
  explanatoryNote: string;
  responseStrategies: string[];
  timestamp: string;
}
```

#### Переиспользуемые компоненты
- `ChapterLinkButton` и `FavoriteButton` - для навигации
- `createBaseExercise` - для создания упражнения
- Паттерн сохранения из `PleasureSheet` - для работы с историей
- Стили из других компонентов главы 7

#### Уникальные особенности
1. **Специфичная структура** - записка-объяснение как центральный элемент
2. **Список стратегий** - динамическое добавление/удаление
3. **Фокус на ожиданиях** - не анализ мыслей, а изменение ожиданий
4. **Эмоциональная нейтральность** - цель не в рациональных ответах, а в принятии

### Отличия от существующих компонентов

#### От `ThreeColumnsBase`:
- Не две колонки, а три отдельных поля
- Акцент на объяснении поведения, а не на противопоставлении

#### От `AngerProsCons`:
- Фокус на конкретном человеке, а не на гневе в целом
- Стратегии реагирования вместо анализа последствий

#### От `HotCoolThoughts`:
- Не замена мыслей, а изменение ожиданий
- Принятие поведения как нормального для этого человека

#### От `RewriteShouldRules`:
- Не отказ от "должен", а переосмысление "должен"
- Принцип: человек должен вести себя так, как он ведет себя

### Психологическая ценность

1. **Снижение фрустрации** - убирает несоответствие ожиданий и реальности
2. **Увеличение контроля** - фокус на своих реакциях, а не на поведении других
3. **Развитие эмпатии** - понимание логики поведения другого человека
4. **Практичность** - конкретные стратегии для реальных ситуаций
