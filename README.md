# Терапия настроения - приложение для самопомощи

Веб-приложение, основанное на книгах Дэвида Бернса "Терапия настроения" и "Близость", помогающее пользователям в борьбе с депрессией и улучшении межличностных отношений через структурированное изучение материала и выполнение практических заданий.

## Основные функции

### 1. Две книги с системой последовательного обучения
- **Книга 1 — "Терапия настроения"**: практическое руководство по когнитивно-поведенческой терапии (19 глав, 7 частей)
- **Книга 2 — "Близость"**: руководство по преодолению одиночества и построению отношений (14 глав, 5 частей + приложения)
- Переключение между книгами через вкладки в меню глав
- Каждая следующая глава становится доступной только после изучения предыдущей (для каждой книги отдельно)
- Интерактивные тесты и задания внутри глав

### 2. Практические задания
- Ежедневные упражнения по 15 минут
- Ведение дневника негативных мыслей
- Анализ и корректировка искаженного мышления
- Таблицы для записи и анализа мыслей

### 3. Отслеживание прогресса
- Календарь выполнения заданий
- Визуализация прогресса по главам
- Статистика выполнения ежедневных упражнений

### 4. Технические особенности
- Одностраничное React-приложение (SPA)
- Хранение данных в localStorage
- Отсутствие необходимости в backend-части
- Возможность использовать приложение без подключения к интернету после первой загрузки

## Структура хранения данных в localStorage

```typescript
interface UserProgress {
  // Прогресс по главам
  chaptersProgress: {
    [chapterId: string]: {
      isCompleted: boolean;
      lastReadPosition: number;
      completedTests: string[];
    }
  };
  
  // Дневник мыслей
  thoughtDiary: {
    entries: {
      date: string;
      situation: string;
      automaticThoughts: string;
      analysis: string;
    }[];
  };
  
  // Календарь выполнения заданий
  exerciseCalendar: {
    [date: string]: {
      exercisesDone: string[];
      timeSpent: number;
    }
  };
}
```
